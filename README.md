# rose-ember-forge.github.io

Personal portfolio site of Raghunandan Rajkumar, live at <https://rose-ember-forge.github.io>.

Built with [Quarto](https://quarto.org) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Edit

- `index.qmd`: pitch, project cards and earlier work
- `about.qmd`: CV summary
- `contact.qmd`: contact links
- `styles.scss`: colours and layout (black, red, grey)
- `files/Raghunandan_Rajkumar_CV.pdf`: the downloadable CV
- `assets/`: avatar and project images

## Preview locally

```bash
quarto preview
```
